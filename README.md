### 👨‍💻 Sobre mim

Sou estudante de **Desenvolvimento de Sistemas no SENAI MG (CTTIT)**, focado no desenvolvimento **Backend com Java**.

Atualmente estou aprofundando meus conhecimentos em **Java, Spring Boot, APIs REST, JPA/Hibernate, JDBC e bancos de dados relacionais**, além de expandir meus estudos para tecnologias web.

Meu objetivo é conquistar minha primeira oportunidade como **Desenvolvedor Java Júnior** e continuar evoluindo através de projetos práticos.

- ☕ Foco principal em **Java & Spring Boot**
- 🌐 Desenvolvimento de **APIs REST**
- 🗄️ Banco de dados com **MySQL**
- 🔗 Persistência utilizando **JDBC e JPA/Hibernate**
- 🧱 Programação Orientada a Objetos e arquitetura em camadas
- 🎨 Estudando **HTML & CSS**
- 🚀 Sempre buscando transformar aprendizado em projetos
